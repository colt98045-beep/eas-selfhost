Live checks run on the launcher Worker with an 8s timeout and a 15s cache; the page refreshes every 20s. Uptime history is sampled every 5 minutes by a cron on the launcher and kept for 30 days; each bar is one ET day. An incident opens when a check is first seen down and closes when it is next seen up. A US Turnstile challenge (HTTP 403) counts as Up, gated — the Worker is up, and this check does not pass the gate or read API bodies. Times are 24-hour America/New_York (ET), dates are DD/MM/YYYY.
Badge: https://img.shields.io/endpoint?url=https://eas-launcher.your-subdomain.workers.dev/api/badge?target=us (targets overall, us, ca, launcher; add &metric=uptime30d for uptime).
